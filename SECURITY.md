# Security policy

## Supported versions

Security fixes go into the latest minor release.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on the repository). You'll get an
acknowledgement within a few days, and a fix or mitigation plan once the report
is confirmed.

AgentStat runs entirely in the browser and makes no network requests. Releases
are published from CI with npm provenance, so you can verify that a package
version was built from this repository.
